## 📌 Project Overview

This project marks my introduction to the practical world of data science through an exploration of real estate listings from Mexico.

The central objective was to investigate the factors influencing residential property prices, with particular attention to two important variables: **property size and location**.

Using real-world property listing data, I worked through the foundational stages of the data science workflow, including data loading, cleaning, transformation, exploratory data analysis, statistical computation, and visualization.

Throughout the project, I explored how property characteristics relate to listing prices and investigated whether property size or geographical location has a stronger relationship with price.

The project provided an opportunity to move beyond theoretical statistical concepts and apply them to real data, developing the analytical thinking and technical foundations necessary for more advanced machine learning projects.

## 🎯 Key Questions

The analysis was guided by the following questions:

- What does the real estate dataset reveal about property prices and characteristics?
- How are property size and listing prices related?
- How does location influence property prices?
- Do price patterns differ across states and property types?
- What can price per square meter tell us about the relative influence of size and location?

## 🔬 Analytical Workflow

The project was structured around four notebooks, each addressing a different stage of the exploratory data analysis process.

### 01. Data Loading & Inspection

- Loaded real estate listing data into Python.
- Inspected the dataset's structure, dimensions, and data types.
- Examined variables and identified potential data quality issues.
- Developed an initial understanding of the available data.

### 02. Data Cleaning & Preparation

- Identified and addressed data quality issues.
- Handled missing and inconsistent values.
- Prepared relevant variables for statistical analysis.
- Used Pandas to transform the raw dataset into a more suitable analytical format.

### 03. Exploratory Data Analysis & Visualization

- Computed descriptive statistics.
- Examined the distributions of important numerical variables.
- Created histograms, box plots, and scatter plots.
- Investigated relationships between property prices, size, and other characteristics.
- Identified patterns and potential outliers.

### 04. Correlation & Comparative Analysis

- Calculated Pearson correlation coefficients.
- Examined relationships between property size and listing price.
- Conducted group-level correlation analysis by state and property type.
- Analyzed price per square meter across different locations.
- Used statistical evidence to investigate the relative influence of property size and location.

## 💡 Key Takeaways

Completing this project strengthened my understanding of the importance of exploratory data analysis as a foundation for effective data science.

Some of my key takeaways include:

1. **Data quality matters:** Reliable analysis begins with understanding, inspecting, and preparing the underlying dataset. The quality of the data directly influences the quality of the insights obtained.

2. **Visualization makes patterns easier to understand:** Histograms, box plots, and scatter plots provide different perspectives on data distributions and relationships that may not be immediately apparent from raw numbers.

3. **Correlation helps quantify relationships:** Pearson correlation provides a useful measure of the direction and strength of linear relationships between numerical variables, although correlation does not establish causation.

4. **Context matters in data analysis:** Examining property prices across different states and property types provides a more nuanced understanding than looking at the dataset as a whole.

5. **Feature interpretation is important:** Comparing price per square meter provides another perspective on property valuation, helping investigate how location and property size relate to market prices.

Most importantly, I learned that data science is not simply about applying algorithms. It begins with asking meaningful questions, understanding the data, and using appropriate analytical techniques to uncover evidence-based insights.
